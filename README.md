# 🎮 Rock, Paper, Scissors - Nexus Boot Camp Project

An interactive, animated, responsive Rock-Paper-Scissors game.

## 🚀 Features

- ✅ 5 or 7 rounds mode selection
- ✅ Real-time scoreboard & round tracking
- ✅ Smooth animations for Win/Lose/Draw
- ✅ Fully responsive (mobile/tablet/desktop)
- ✅ Restart game option
- ✅ Keyboard shortcuts (R, P, S keys)
- ✅ Font Awesome icons

## 🛠️ Tech Stack

- HTML5
- CSS3 (Animations, Flexbox, Grid, Media Queries)
- JavaScript (ES6+)
- Font Awesome Icons

## 🎯 How to Play

1. Select game mode (Best of 5 or 7 rounds)
2. Click Rock, Paper, or Scissors
3. Watch the animation and result
4. First to win 5/7 rounds wins the game!
5. Click "New Game" to restart or double-click to change mode

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| R | Play ROCK |
| P | Play PAPER |
| S | Play SCISSORS |

## 📱 Responsive

- Desktop: 3 buttons side by side
- Tablet: Stacked layout with adjusted sizes
- Mobile: Optimized touch targets

## 🎨 Animations

- **Win**: Green pulse effect
- **Lose**: Red shake effect
- **Draw**: Yellow blink effect

## 📝 SOLID Principles Applied

- **S**: Single Responsibility (each function does one thing)
- **O**: Open-Closed (easy to add Lizard/Spock)
- **L**: Liskov Substitution (functions are reusable)
- **I**: Interface Segregation (UI vs logic separated)
- **D**: Dependency Inversion (abstractions not hardcoded)
